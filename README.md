# 🌍 Earth First Portal

A **Salesforce-based Community Sustainability Platform** built during my internship at **Cognizant** to streamline environmental issue reporting, volunteer management, and sustainability initiatives through a unified Experience Cloud portal.

---

## 🚀 Features

- 🌱 Environmental Issue Reporting
- 🤝 Volunteer & Initiative Management
- 🏆 Gamification & Leaderboard
- 🔔 Custom Notifications
- 📊 Reports & Dashboards
- 🔒 Role-Based Access Control

---

## 🛠️ Tech Stack

**Salesforce CRM** • Apex • Lightning Web Components (LWC) • Experience Cloud • SOQL • Flows • Apex Triggers • Reports & Dashboards
